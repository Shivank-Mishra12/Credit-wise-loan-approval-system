This is the minor project related to finance problem. A bank who have large amount data of laon approval whenever we analyze this take longer time and high cost 
so we try to build a supervised machine learning model that can predict the loan approved / loan not approved for user .

we use python library like pandas, numpy, seaborn for visualization. Handel missing values, Perform EDA process.
Train Test Split and feature scaling, Train the model using Logistic Regression, KNN Classifier, Naive Bayes  & Evaluate all the Models using evaluation metrics
like accuracy, precision, recall, F1 score. Find the best model for this problem.
